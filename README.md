# Hi-Trail — сайт лиги спорта и туризма

UI-прототип нового сайта [hi-trail.ru](http://hi-trail.ru) — лиги любительского спорта Приднестровья
(НП «Лига спорта и туризма „Хай-Треил“», ~25 стартов в год: бег/трейл, вело XCM, открытая вода, мультиспорт).

**Статус: прототип (v5).** Всё состояние живёт в памяти браузера — без бэкенда и сохранения.
Данные событий реальные (календарь 2026, программы, взносы, рекорды), протоколы и суммы сборов — демо.

## Что внутри

- **Календарь** — карточки-«стартовые номера»: теги лиг, слоганы, пиктограммы дисциплин,
  бейджи слотов («Осталось N», «Продано»), фильтры, закреп «Лига собирает»
- **Страница события** — слоган, дистанции-рассказы с рекордами, программа, взносы и скидки,
  документы, отзыв, слоты, Telegram-чат
- **Регистрация** — категория по году рождения, допродажи (именной номер, футболка, бафф, шапочка),
  донат в сбор, расчёт итога
- **Результаты** — поиск по фамилии по всем протоколам, протоколы по дистанциям
- **Кубок** — формула «очки каждому финишёру» (R = 1000 × T лидера / T участника + бонусы),
  лиги (Ночная/Водная/Вело), клубный зачёт
- **Сборы** — «Безопасная трасса» и «Хай-Трейл Мобиль»: прогресс-бары, смета, экипаж
- **Магазин** — мерч под заказ с выдачей на старте, подарочный сертификат
- **Личный кабинет** — регистрации, история, очки Кубка, «к выдаче на старте», бейдж мецената
- **Админка** (кнопка ⚙) — события, заявки с подтверждением оплат, партнёры, сборы; редактор события
- **4 фирменных стиля** — переключатель слева внизу («Сигнальная лента» — основной)

Лист логотипа: `docs/logo-sheet.svg`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # посмотреть сборку локально
```

## Деплой

**Vercel / Netlify (проще всего):** импортировать репозиторий, фреймворк определится сам
(Vite), команда `npm run build`, папка `dist`. Ничего настраивать не нужно.

**GitHub Pages:** уже настроен workflow `.github/workflows/deploy.yml`.
В репозитории включить Settings → Pages → Source: **GitHub Actions** — деплой при каждом пуше в `main`.

## Структура

```
src/App.jsx    — весь прототип: данные, стили, страницы (намеренно один файл)
src/main.jsx   — точка входа
docs/          — лист логотипа
```

## Дорожная карта (после прототипа)

- **Этап 0 — фундамент:** БД (events/distances/registrations/payments/users/results),
  auth по magic-link, деплой на HTTPS; замена Google Forms
- **Этап 1 — кабинет и результаты:** импорт протоколов CSV, миграция архива 2020–2026
- **Этап 2 — конверсия каталога:** слоты, теги, отзывы, TG-чаты — контент
- **Этап 3 — Кубок и лиги:** автоматический расчёт очков, клубный и корпоративный зачёты
- **Этап 4 — сервисы:** форматы-лендинги, Race Book PDF, гиды локаций, фото по номеру, live
